The foundation
01 / Master Prompt V1.3

Grounding AI in veterinary knowledge.

The Canine Thorax Master Prompt v1.3 was shaped with input from Dr. Parin Candy and informed by veterinary textbooks. Not just simply generic prompting alone.

Why one master prompt?
One consistent instruction framework across 20 conditions. Saves from tokenmaxxing.

It defines the AI's role, task, guidelines, condition definitions, expected output, restrictions and handling of uncertain cases.

The comparison
06 / What did Claude Code improve?

The clearest improvement was how the application was organised and checked.

Week 4 · Original application

Working foundation

  • Functional end-to-end evaluation pipeline
  • Master Prompt V1.3 and structured LLM output
  • Two evaluation concepts and recoverable batch runs
  • Compact codebase, but duplicated loaders and gaps in evaluation-source provenance
Week 5 · Claude Code rebuild

Engineering maturity

  • More modular and reusable architecture
  • Matrix 2 evaluator added to codebase
  • Parity checks reproduced Week 4 baseline confusion counts
  • More systematic automated testing and workflow controls
Claude Code did well: structure, repeatability, evaluation-source completeness and verification.
Human review remained essential: correcting assumptions, validating methodology, fixing Windows issues and reviewing documentation.
Conclusion
07 / The takeaway
The human + AI development loop

AI can build.
Human judgement makes it dependable.

Week 4 established the working application. Week 5 strengthened its engineering foundations. The most valuable outcome came from combining AI-assisted development with domain-informed prompts, evidence and human oversight.
