# Data Dictionary

Covers the two source files and the derived datasets produced by `analysis/`. Derived files are
regenerated by `python analysis/run_all.py`; never edit them by hand.

**Encoding conventions (all derived CSVs):** UTF-8; datetimes `YYYY-MM-DD HH:MM:SS` (source-local wall
clock, no timezone); date-only columns (`*_date`, `date_of_birth`) `YYYY-MM-DD`; flags `1` / `0`;
blank = missing. Import as genuine date/datetime types and apply `DD-MM-YYYY` as the *display* format.

---

## 1. Source files (`data/raw/`, read-only)

### 1.1 Intakes — 173,812 rows × 12 columns

| Column | Format | Meaning / notes |
|---|---|---|
| Animal ID | `A` + 6 digits | Animal identifier. Persists across visits; **not** a visit key. |
| Name | text | Animal name; 28.76% blank. A leading `*` appears to denote a shelter-assigned name (assumption). |
| DateTime | `MM/DD/YYYY hh:mm:ss AM/PM` | Intake timestamp, local wall clock, no offset. |
| MonthYear | `Month YYYY` | Month of DateTime (redundant). |
| Found Location | free text | Where the animal was found, typically "address in City (TX)". |
| Intake Type | category | Stray, Owner Surrender, Public Assist, Wildlife, Abandoned (from 2020), Euthanasia Request. |
| Intake Condition | category | 20 labels, e.g. Normal, Injured, Sick, Nursing, Neonatal. Not ordinal. |
| Animal Type | category | Dog, Cat, Other (mostly wildlife), Bird, Livestock. |
| Sex upon Intake | category | Intact/Neutered Male, Intact/Spayed Female, Unknown; 1 `NULL`. |
| Age upon Intake | `N unit(s)` | Age at intake, derived from DOB in the source; 10 negative values. |
| Breed | text | 3,006 labels; `Mix` and `/` combinations common. |
| Color | text | 661 labels. |

### 1.2 Outcomes — 173,775 rows × 12 columns

| Column | Format | Meaning / notes |
|---|---|---|
| Animal ID | `A` + 6 digits | As above. |
| Date of Birth | `YYYY-MM-DD` | Estimated DOB; 33 later than the outcome date. |
| Name | text | 28.65% blank. |
| DateTime | ISO-8601, `YYYY-MM-DDThh:mm:ss[-05:00]` | Outcome timestamp, local wall clock. The `-05:00` suffix (3,584 rows) appears only on midnight, date-only records and is not a reliable timezone (D-008). |
| MonthYear | `MM-YYYY` | Month of DateTime (redundant). |
| Outcome Type | category | Adoption, Transfer, Return to Owner, Euthanasia, Died, Rto-Adopt, Disposal, Missing, Relocate, Stolen, Lost; 46 blank. |
| Outcome Subtype | category | 26 labels; 54.16% blank. Meaning depends on Outcome Type (e.g. Transfer/Partner, Transfer/Snr, Adoption/Foster, Euthanasia/Suffering). |
| Animal Type, Sex upon Outcome, Breed, Color | as intakes | 1 `NULL` sex. |
| Age upon Outcome | `N unit(s)` | 10 negative, 9 `NULL`. |

## 4. `outputs/matching/candidate_visits.csv` — visit fact table (174,753 rows)

One row per matched visit (172,772), per unmatched intake (1,004) and per unmatched outcome (977).
Exact duplicate copies are excluded. Method `adjacent_dp` (D-010 to D-012).

| Column | Type | Definition |
|---|---|---|
| visit_id | text | `V-` + intake_event_id (or + outcome_event_id for outcome-only rows). Primary key. |
| visit_status | category | Matched visit · Intake without matched outcome · Outcome without matched intake. |
| matching_method | text | `adjacent_dp` for every row. |
| match_rule | category | chronological · same_day_time_reversed (D-012) · unmatched. |
| animal_id | text | Animal ID. |
| intake_event_id / outcome_event_id | text | Foreign keys to the cleaned event tables. |
| intake_datetime / outcome_datetime | datetime | Event timestamps as stored. |
| intake_date / outcome_date | date | Event dates. |
| los_days | number | Length of stay in days, ≥ 0; blank unless matched. **Basis for the LOS measure.** |
| los_days_raw | number | Raw (negative) duration, populated only where floored. |
| los_floored_to_zero | flag | Raw duration < 0 (same-date events only) and set to 0. |
| los_band | category | Under 1 day, 1-6, 7-29, 30-89, 90-179, 180-364, 365+ days. |
| same_day_visit | flag | Intake and outcome on the same calendar date. |
| long_stay_365plus | flag | los_days > 365. |
| animal_type | category | Intake animal type (outcome type for outcome-only rows). |
| animal_type_mismatch | flag | Intake and outcome animal type differ (0 for all rows). |
| intake_type, intake_condition, age_upon_intake_days, age_band_intake, breed_is_mix | | From the intake event. |
| outcome_type, outcome_subtype, outcome_group, outcome_status_provisional | | From the outcome event. |
| animal_intake_ordinal | integer | 1 = the animal's first analytic intake in the extract, 2 = second, … |
| is_return_intake | flag | animal_intake_ordinal > 1 (a repeat visit). |
| multiple_open_intakes | flag | More than one intake was open when the outcome occurred (earlier one superseded). |
| n_eligible | integer | Number of open intakes when the outcome was assigned. |
| assignment_method_dependent | flag | Animal's pairing differs between FIFO/LIFO/adjacent or had multiple open intakes (45 animals). |
| intake_id_timestamp_conflict | flag | Intake is part of a same-ID/same-timestamp conflict. |
| outcome_is_midnight / outcome_time_is_date_only | flag | From the outcome event. |
| intake_age_dob_gap_days | number | \|intake age − (intake date − DOB)\|; diagnostic only. |
| days_open_at_extract_end | integer | For intake-only rows: days from intake date to 05-05-2025. |

Breed, sex, name and color are not repeated here; join on `intake_event_id` / `outcome_event_id`.

## 5. Audit and analysis outputs

`outputs/audit/` — profiles and exception lists (see `docs/DATA_AUDIT_REPORT.md` for each file).
`outputs/analysis/` — time series and opportunity evidence (see `docs/BUSINESS_OPPORTUNITY_REGISTER.md`).
Key conventions there: `*_events` = analytic event counts (exact duplicates removed), `*_rows_raw` =
source rows; `share_pct` with a `denominator_visits` column = visit-level share; `full_year` /
`partial_or_censored_cohort` mark partial periods.
